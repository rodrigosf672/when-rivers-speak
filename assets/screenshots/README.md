# Screenshots

Static previews rendered from the bundled sample dataset (RI · MA · CO · CA,
discharge + gage height, 2021–present). In the live app, maps are interactive
deck.gl layers.

| File | Tab / content |
|---|---|
| `map_national_pulse.png` | National River Pulse — latest conditions by anomaly level |
| `chart_timeseries.png` | Historical Explorer — daily mean + rolling averages |
| `chart_state_ranking.png` | State Comparison — anomaly burden ranking |
| `chart_changes.png` | River Change Detector — top sudden rises |
| `chart_coverage.png` | Data Coverage Observatory — sites by state/parameter |
| `metrics_validation.png` | Metrics & anomaly-score validation on a real gauge |

## Capturing live screenshots

Run the app (`marimo run app.py`), open each tab, and capture the browser
viewport. Replace these static previews with live captures for the best README.
